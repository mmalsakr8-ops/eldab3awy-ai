# الضبعاوي AI

نسخة تأسيسية كاملة لمنصة عربية لإدارة أفكار مشاريع المحتوى والسيناريوهات والمشاهد والشخصيات.

## الموجود
- تسجيل وإنشاء حساب + تسجيل دخول وخروج.
- جلسات آمنة عبر Cookie HttpOnly مع انتهاء تلقائي.
- لوحة تحكم عربية RTL.
- إنشاء وتعديل وحذف المشاريع.
- بيانات المشروع: الفكرة، النوع، النبرة، اللغة، الحالة.
- محرر سيناريو مستقل محفوظ في D1.
- إدارة الشخصيات.
- إدارة المشاهد مع الوصف والحوار والـ visual prompt.
- API JSON بسيطة للواجهة.
- صفحة Health.
- هوية الضبعاوي AI وملف logo.svg.

## قاعدة البيانات
D1 binding: `DB`
Database: `eldab3awy-db`

نفّذ schema.sql مرة واحدة على D1 إذا لم تكن الجداول موجودة:
`npx wrangler d1 execute eldab3awy-db --remote --file=schema.sql`

## النشر
`npx wrangler deploy`

## ملاحظة
توليد المحتوى بالذكاء الاصطناعي عبر مزود خارجي لم يُربط بعد؛ البنية الحالية مجهزة لإضافته لاحقًا بدون إعادة بناء الحسابات والمشاريع.
